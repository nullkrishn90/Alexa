## Short description (2-3 lines)

ALEXA PROTECT ek one-command APK protection toolkit hai. Ye tumhari app ki
strings (URL, naam, key) ko encrypt karta hai, class/package naam chhupata
(`MainActivity` -> `I.I`), runtime guards (root / emulator / debugger / hooking
/ resign) lagata hai, aur APK ko apne aap v1+v2+v3 se sign karta hai — taaki
har Android device pe install ho.
